# LOVEE — demo (PWA)

Bu depo yalnızca LOVEE v0.5'in derlenmiş **tanıtım sürümünü** içerir (kaynak kod değil).
Profiller örnektir, gerçek kişi değildir; veriler yalnızca açan kişinin tarayıcısında kalır ve
hiçbir sunucuya gönderilmez. Adres: https://cilingir0961.github.io/lovee-pwa/
iPhone: Safari → Paylaş → Ana Ekrana Ekle.

## Kurulum (PWA)
- iPhone: Safari'de aç → Paylaş → **Ana Ekrana Ekle**.
- Android: Chrome'da aç → menü → **Ana ekrana ekle / Uygulamayı yükle**.
